LEARNSPACE – COMPLETE UI/UX USABILITY PROJECT
================================================

FILES
- index.html: interactive student learning portal prototype. Open in a browser.
- Usability_Evaluation_Report.docx: editable internship report.
- Typeform_Questionnaire.csv: questions to copy into Typeform.

IMPORTANT
This is a complete demonstration package, not evidence of completed real-world user research.
The website uses fictional student/course data. Resource opening, profile saving and assignment
submission are simulated. Example heuristic issues and ratings in the report must be verified
against your final design. No actual Maze study or Typeform survey has been run.
To complete empirical validation, publish your Figma prototype, run the tasks with participants,
collect survey responses, and replace the report's results placeholders with real observations.
